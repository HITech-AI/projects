# HITech-AI Projects

> "智启新航"AI研学社 · 项目库

HITech-AI 是"智启新航"AI研学社的 GitHub 开源组织。本仓库承载社团的项目成果：**黑客松作品、AI 竞赛项目、社团开发项目与内部工具**。

## 仓库定位

以目录组织项目，一个项目一个文件夹，避免拆出过多仓库：

```
projects/
├── hackathon-2026/   # 某一届黑客松作品
├── hackathon-2027/   # 下一届黑客松作品
├── contest/          # AI 竞赛项目
├── club-tools/       # 社团内部工具（管理 Agent / 软件）
└── README.md
```

## 使用约定

- 每个项目自带 `README.md`，说明用途与使用方式
- 遵循"**仓库固定、目录扩展**"原则：项目按文件夹归档，不为单个项目新建仓库
- 支持通过 Topic 打标签（`hackathon`、`contest`、`tool`）辅助检索

## 如何贡献

1. Fork 本仓库
2. 新建分支，在对应项目目录中完成开发
3. 提交 Pull Request
