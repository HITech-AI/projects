# HITech-AI Projects

> **"智启新航"AI 研学社 · 项目库** · 让创意落地，用项目成长

本仓库承载社团的项目成果：**黑客松作品、AI 竞赛项目、社团开发项目与内部工具**。一个项目一个文件夹，以目录组织，避免拆出过多仓库。

## 目录结构

```
projects/
├── hackathon/        # 黑客松作品（按届次建子目录）
├── contest/          # AI 竞赛项目
├── club-tools/       # 社团内部工具（管理 Agent / 软件）
├── tutorials/        # 学习型项目（如 hello-agents 练习作业）
└── README.md
```

> 新项目**按类型加目录**，不为单个项目新建仓库。

## 项目规范

每个项目目录须包含一个 `README.md`，说明：

- **背景**：这个项目做什么、为什么做。
- **功能**：核心能力与使用方式。
- **运行**：环境要求、如何运行。
- **贡献**：如何参与该项目。

## 生命周期

- **孵化** → 提出 idea，先行讨论，建立项目目录。
- **进行** → 团队开发，持续推进。
- **完成 / 归档** → 稳定可用或暂停，在 README 中标注状态。

## 如何贡献

1. 阅读 [CONTRIBUTING](https://github.com/HITech-AI/HITech-AI/blob/main/CONTRIBUTING.md)。
2. Fork 本仓库，在对应项目目录中开发。
3. 提交 PR；每个项目可打 Topic（`hackathon`、`contest`、`tool`、`tutorial`）辅助检索。
